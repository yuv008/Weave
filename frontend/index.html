Run the downloaded WeavePetSetup.exe. The file name carries a short-lived code. That one run writes pet.config.json, adds Weave in .cursor/mcp.json, starts the pet, and places the Gmail extension in %LOCALAPPDATA%\Weave\Pet\gmail. A coded file replaces pet.config.json and refreshes Cursor. A file with no code keeps pet.config.json and adds Weave only when that server is missing. After the installer finishes, open chrome://extensions, turn on Developer mode, and load that unpacked gmail folder — this is a required setup step. The Chrome Web Store listing is not yet published; loading the folder unpacked is how you install it now. You do not need the Weave source code. Read the pet walkthrough for what each step does.

Your tokens

  
Each download and each Open Weave makes a token that lasts 30 days. Revoke one you no longer use, or all of them if a laptop is lost. A revoked token stops working within a minute; an expired one needs a new download.
