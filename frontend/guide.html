Weave Pet

The Windows companion for Weave. One installer run connects everything — it configures your login, adds Weave to Cursor's MCP, and opens the pet. You do not need the Weave source code.

Back to setup

Three steps: connect a source → download & run the installer → type @bubble in Cursor or Gmail. That's it.

1. Connect a source

  1. Sign in to Weave (or create a company if this is your first time). Enter the company name and save it.
  2. Connect at least one tool. Slack, Notion, Google Drive, and GitHub are available. HubSpot is shown but not connectable yet. One connection is enough.

2. Download & run the installer — one click

On the setup page, choose Download the Windows pet. The file saves as WeavePetSetup-<code>.exe with a short-lived code (15 minutes). Run it once — that is all you need.

That single run does everything:

  • Redeems the code and writes pet.config.json into %LOCALAPPDATA%\Weave\Pet.
  • Merges the Weave MCP server into %USERPROFILE%\.cursor\mcp.json, leaving your other servers untouched.
  • Places the Gmail extension in %LOCALAPPDATA%\Weave\Pet\gmail.
  • Opens Weave Pet and creates a Start menu entry.

A file named WeavePetSetup-<code>.exe replaces pet.config.json and refreshes the Cursor server. Running WeavePetSetup.exe with no code keeps the existing pet.config.json, and adds Weave in .cursor/mcp.json only when that server is missing.

3. Use Weave

Weave Pet works in two places. Both are required — Cursor for writing code and docs, Gmail for composing email. Keep the pet running in both cases.

Cursor @bubble

  1. In Cursor chat — the box where you type a message to the agent — type @bubble and your question, then pause.
  2. @bubble turns purple when the pet sees it. A dot appears on the pet.
  3. The answer card opens with the answer, a short quote, and the source.
  4. Choose Approve. The @bubble sentence is replaced with the answer.
  5. Choose Reject to close the card without changing what you typed.

The installer also adds Weave as an MCP server in Cursor settings. The Approve and Reject card still comes from Weave Pet, and it works in that chat box.

Gmail @bubble

  1. In Chrome, open chrome://extensions, turn on Developer mode, and choose Load unpacked.
  2. Select %LOCALAPPDATA%\Weave\Pet\gmail. The installer placed it there. The Chrome Web Store listing is not yet published — loading the folder unpacked is the only install method right now.
  3. Open a Gmail draft. Type @bubble and the question, then pause.
  4. The pet shows the card with the answer, a quote, and the source.
  5. Choose Approve. The answer is written into the draft. You still send the email.
  6. Choose Reject to leave the draft exactly as typed.

The extension talks to the pet on 127.0.0.1:8766. Weave Pet must be running.

Troubleshooting

  • Pet asks for pet.config.json: the login file is missing from %LOCALAPPDATA%\Weave\Pet. On the setup page, choose Download the Windows pet again — a fresh installer writes a new file. Or choose Open Weave, download the file manually, and save it next to WeavePet.exe, then reopen the pet from the Start menu.
  • No card after @bubble in Cursor: make sure Weave Pet is running. If the pet is running and no card appears, the company notes may not contain a matching answer — try a more specific question.
  • Gmail does not respond: the extension only works when Weave Pet is running. Check that %LOCALAPPDATA%\Weave\Pet\gmail is loaded in chrome://extensions and that Weave Pet is open.
  • Install code expired: the code in the file name lasts 15 minutes. Go back to the setup page, choose Download the Windows pet again, and run the new file.
